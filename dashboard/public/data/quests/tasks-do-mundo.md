Resumo rápido: estas são as Tasks oferecidas por NPCs espalhados pelo mundo. A tabela reúne os objetivos e todas as recompensas configuradas atualmente no servidor.

Como iniciar e concluir#
Encontre o NPC responsável e aceite a Task no diálogo.
Abra Tasks no menu superior para acompanhar os objetivos.
Conclua todas as derrotas ou entregas solicitadas.
Volte ao mesmo NPC para receber as recompensas.

O painel Tasks apenas acompanha o progresso. A aceitação e a entrega continuam sendo feitas diretamente com o NPC. Consulte também o Task Tracker.

Como ler as recompensas#
quando uma Task possui várias entregas, elas aparecem como Etapa 1, Etapa 2 e assim por diante;
quando houver um Pokémon como recompensa, a Poké Ball utilizada aparece entre parênteses;
a configuração atual do servidor é a referência para itens, quantidades e experiência.
