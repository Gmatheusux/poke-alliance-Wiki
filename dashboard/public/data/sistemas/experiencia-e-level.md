Esta página explica os cortes da experiência recebida, permite consultar quanto de XP total é necessário para alcançar qualquer level e estima a perda de experiência na morte.

A Wiki apresenta os valores finais de experiência, sem divulgar a fórmula interna utilizada pelo servidor.

Cortes de XP por faixa de level#

Os cortes abaixo são aplicados à experiência base obtida ao derrotar criaturas. Bônus ativos de outros sistemas podem alterar o valor final recebido.

FAIXA DE LEVEL	XP BASE RECEBIDA	EXEMPLO SOBRE 1.000 XP
1 a 99	100%	1.000 XP
100 a 129	80%	800 XP
130 a 149	60%	600 XP
150 a 199	40%	400 XP
200 a 319	12,5%	125 XP
320 a 399	5%	50 XP
400 a 8000	1%	10 XP

O novo percentual passa a valer assim que o jogador alcança o primeiro level da faixa.

Nota: a base de 1.000 XP serve apenas para demonstrar o efeito de cada corte. Usar uma criatura inicial, como Geodude, como referência para um jogador de level 500 não representa a progressão real: nessa faixa, o jogador caça em áreas muito mais avançadas, com criaturas que fornecem uma quantidade de experiência base muito maior.

Perda de XP na morte#
antes do level 50, nenhuma experiência é descontada;
a partir do level 50, a perda varia conforme o level e o progresso atual;
Bless reduz em 70% a perda que aconteceria sem proteção;
Bless Plus reduz em 92% a perda que aconteceria sem proteção.

Bless e Bless Plus são consumidas quando protegem uma morte para criatura.

Como o valor depende do progresso dentro do level, use a calculadora para obter a estimativa correspondente à situação do personagem.

Como interpretar os valores#
XP total para o level: total acumulado que o personagem precisa alcançar.
XP desde o level anterior: diferença entre o início do level anterior e o level consultado.
XP para o próximo level: experiência necessária para preencher completamente o level atual.
XP atual estimado: total aproximado considerando o percentual de progresso informado.
